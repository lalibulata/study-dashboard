# Study dashboard

Static website with private, per-account Supabase synchronization.

Upload the contents of this directory to the repository root. Enable GitHub Pages from main / root.

This release contains no personal score records, classroom locations, study journals, or JSON backups. The Supabase publishable key is a public browser key; database access requires user login and row-level authorization.

Sign in with the same email on both devices. On a new device choose the cloud restore option.

Supabase JavaScript client 2.118.0 is distributed with its license in supabase-LICENSE.txt.
